Integration snippet

Paste this into your other website:

<!-- SSO Login Button -->
<div id="sso-login-btn"></div>
<script src="{{ base_url }}/oauth/widget.js?client_id={{ app.client_id }}&redirect_uri=YOUR_CALLBACK_URL"></script>

Or link directly:

{{ base_url }}/oauth/authorize?client_id={{ app.client_id }}&redirect_uri=YOUR_CALLBACK_URL&response_type=code&scope=profile

Exchange the code for a token (server-side POST):

POST {{ base_url }}/oauth/token
Content-Type: application/x-www-form-urlencoded

grant_type=authorization_code
&code=CODE_FROM_REDIRECT
&redirect_uri=YOUR_CALLBACK_URL
&client_id={{ app.client_id }}
&client_secret=YOUR_CLIENT_SECRET

Then get user info:

GET {{ base_url }}/oauth/userinfo
Authorization: Bearer ACCESS_TOKEN

How It Works
  1. Register your external website here to get a Client ID and Client Secret.
  2. Add the widget snippet (or a link) to your site.
  3. Users click "Sign in" and are sent here to log in and approve.
  4. They are redirected back with a code.
  5. Your server exchanges the code for an access token.
  6. Use the token to call /oauth/userinfo to get their profile.
